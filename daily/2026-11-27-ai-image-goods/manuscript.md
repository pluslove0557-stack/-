# AI 이미지로 굿즈·스티커 팔기
_그림을 못 그려도 시작하는 기획·인쇄 파일·판매 실전 가이드_

# 프롤로그

귀여운 스티커, 감성 엽서, 나만의 키링. 그림을 잘 그리지 못해도 이런 디자인 상품을 만들어 팔 수 있을까요? AI 이미지 도구가 나오면서 이 질문에 '시작은 해 볼 수 있다'고 답할 수 있게 되었습니다. 다만 AI로 그림을 뽑는 것과 **팔 수 있는 상품**을 만드는 것 사이에는 꽤 많은 단계가 있습니다.

이 책은 그 사이의 단계를 순서대로 안내합니다. 팔릴 만한 주제를 고르고, 한 세트처럼 보이는 그림을 만들고, 인쇄에 맞는 파일로 다듬고, 소량 제작과 판매 채널을 정하고, 상세페이지까지 꾸리는 과정입니다. 그리고 무엇보다 **저작권과 상표, 도구 이용약관**을 확인하는 방법을 함께 다룹니다.

> 이 책의 약속: 마지막 장을 덮으면 스티커 한 세트(6~8종)의 기획안, 인쇄용 파일 준비 순서, 첫 판매 채널 계획을 손에 쥐게 됩니다.

이 책은 판매량이나 수익을 약속하지 않습니다. 결과는 디자인, 가격, 채널, 홍보에 따라 크게 달라집니다. 또한 AI 생성물의 저작권 인정 범위, 각 AI 도구의 상업적 이용 조건, 판매 플랫폼 정책은 나라와 시기에 따라 다르고 자주 바뀝니다. 책에 적힌 내용은 **작성일(2026년 11월) 기준의 일반적인 안내**이며 법률 자문이 아닙니다. 판매 전에 반드시 최신 약관과 공식 안내를 확인하세요.

# 1장. 시작 전 확인: 저작권·상표·도구 약관

## 도구 약관에서 볼 세 가지

AI 이미지 도구마다 상업적 이용 조건이 다릅니다. 쓰려는 도구의 이용약관에서 아래 세 가지를 확인하고 캡처해 두세요(작성일 기준, 약관은 바뀔 수 있습니다).

| 확인 항목 | 볼 내용 |
|---|---|
| 상업적 이용 | 만든 이미지를 판매용 상품에 써도 되는지, 유료 요금제에서만 가능한지 |
| 권리 귀속 | 결과물의 권리가 누구에게 있다고 적혀 있는지 |
| 금지 사항 | 실존 인물, 특정 작가 화풍 모방 등 금지된 사용 |

약관을 확인한 날짜와 캡처를 폴더에 보관해 두면 나중에 문의가 왔을 때 도움이 됩니다.

## 피해야 할 소재

아래 소재는 AI로 만들었더라도 저작권·상표권·초상권 문제가 생길 수 있어 판매용으로 쓰지 않습니다.

- 만화·게임·애니메이션 캐릭터, 또는 그와 닮게 만든 그림
- 브랜드 로고, 상표, 스포츠 팀 엠블럼
- 연예인·유명인 등 실존 인물의 얼굴
- "○○ 작가 스타일로"처럼 특정 작가 이름을 넣어 만든 그림
- 다른 판매자의 디자인을 참고 이미지로 넣어 비슷하게 만든 그림

판매하려는 문구나 이름이 상표로 등록되어 있는지는 특허청의 상표 검색 서비스(키프리스 등)로 확인해 볼 수 있습니다.

## AI 생성물과 권리에 대해 알아 둘 점

사람의 창작적 기여 없이 AI가 만든 결과물은 저작권 보호를 받기 어렵다는 것이 여러 나라의 일반적인 입장입니다(작성일 기준). 이 말은 **내 디자인을 다른 사람이 따라 해도 막기 어려울 수 있다**는 뜻이기도 합니다. 그래서 이 책에서는 AI 그림을 그대로 파는 대신, 내가 직접 고르고 배치하고 문구를 넣고 수정하는 과정을 거치는 방법을 권합니다.

권리 문제가 걱정되는 상품이라면 판매 전에 전문가나 공공 상담 창구(한국저작권위원회 등)의 안내를 받으세요.

# 2장. 주제 고르기: 누구의 일상에 붙을 스티커인가

## 상품 유형 고르기

처음에는 제작비가 낮고 실패 부담이 적은 상품부터 시작하세요.

| 상품 | 장점 | 주의할 점 |
|---|---|---|
| 스티커(낱장·씰) | 소량 제작 가능, 배송 쉬움 | 칼선(모양 따라 자르기) 파일 필요 |
| 엽서·카드 | 단순한 사각 인쇄 | 종이·코팅 선택에 따라 느낌 차이 |
| 메모지·떡메 | 실용성이 높음 | 낱장 수·제본 방식 확인 |
| 키링·아크릴 | 단가가 높음 | 최소 주문 수량이 있는 경우가 많음 |
| 디지털 다운로드(배경화면, 다꾸 PNG) | 재고 없음 | 무단 공유될 수 있음 |

이 책에서는 **스티커 한 세트**를 기준으로 설명합니다.

## 타깃과 상황으로 주제 좁히기

"귀여운 동물 스티커"는 너무 넓습니다. 누가, 어디에, 언제 붙일지를 정하면 주제가 선명해집니다.

> [누가]가 [어디에] [어떤 순간]에 붙이는 스티커

예) 수험생이 공부 플래너에 하루 목표를 끝냈을 때 붙이는 스티커
예) 반려견 보호자가 산책 일기에 붙이는 날씨·기분 스티커

## AI로 세트 아이디어 뽑기

> 나는 [타깃]을 위한 스티커 세트를 기획하고 있어. 사용 상황은 [상황]이야.
> 1) 이 사람들이 공감할 만한 짧은 문구 20개를 만들어 줘 (8자 이내, 존댓말·반말 섞어서)
> 2) 문구와 어울리는 그림 소재를 하나씩 붙여 줘
> 3) 그중 한 세트로 묶기 좋은 8개를 골라 이유와 함께 알려 줘
> 캐릭터·브랜드·유명인을 연상시키는 소재는 빼 줘.

받은 목록은 그대로 쓰지 말고, 실제 그 상황의 사람들이 쓰는 말투인지 SNS나 커뮤니티 글에서 직접 확인하세요.

# 3장. 그림 만들기: 한 세트처럼 보이는 일관성

## 스타일 고정 프롬프트

세트를 만들 때는 **변하지 않는 부분**과 **바뀌는 부분**을 나눠 프롬프트를 씁니다.

> [고정] 귀여운 손그림 느낌의 스티커 일러스트, 굵고 일정한 검은 외곽선, 파스텔 톤 3색 이내, 흰 배경, 그림자 없음, 정면 구도, 글자 없음
> [변경] 주제: 산책 후 물 마시는 강아지

고정 부분은 메모장에 저장해 두고 매번 똑같이 붙여 넣습니다. 색상은 미리 정한 색 코드 3~4개로 제한하면 세트 느낌이 강해집니다.

## 한 장씩 만들고 고르는 순서

1. 주제 하나에 4~8장을 생성한다
2. 외곽선 굵기·색감·비율이 기준에 맞는 것만 남긴다
3. 고른 그림을 옆에 나란히 놓고 세트로 어울리는지 본다
4. 어긋나는 그림은 프롬프트의 변경 부분만 고쳐 다시 만든다
5. 도구에 '참고 이미지' 기능이 있다면 이미 고른 내 그림을 넣어 스타일을 맞춘다 (다른 사람 작품은 넣지 않는다)

## AI 그림에서 자주 생기는 문제

| 문제 | 확인 방법 | 해결 |
|---|---|---|
| 손가락·발 개수 이상 | 확대해서 하나씩 세기 | 다시 생성하거나 편집 도구로 수정 |
| 그림 속 이상한 글자 | 프롬프트에 '글자 없음' 넣기 | 글자는 나중에 직접 넣는다 |
| 외곽선이 끊김 | 확대해서 테두리 확인 | 편집 도구로 이어 그리기 |
| 배경이 완전히 흰색이 아님 | 배경 제거 후 투명도 확인 | 배경 제거 도구 사용 |

**글자는 AI에게 맡기지 말고** 디자인 도구에서 상업 이용 가능한 글꼴로 직접 넣으세요. 직접 고르고 배치한 문구와 구성이 내 상품의 차별점이 됩니다.

- [ ] 세트 8종 생성하고 고르기

# 4장. 인쇄용 파일 만들기: 해상도·여백·칼선

## 인쇄 파일 기본 용어

| 용어 | 뜻 | 확인할 것 |
|---|---|---|
| 해상도 | 인쇄 품질. 보통 300dpi가 기준으로 많이 쓰인다 | 실제 인쇄 크기에서 픽셀 수가 충분한가 |
| 재단 여백(도련) | 자를 때 밀려도 흰 줄이 안 생기게 바깥으로 늘린 영역 | 업체가 요구하는 mm |
| 안전 영역 | 잘려도 되지 않을 글자·그림이 들어갈 안쪽 영역 | 글자가 이 안에 있는가 |
| 칼선 | 스티커 모양대로 자르는 선 | 업체가 정한 색·형식으로 그렸는가 |
| CMYK | 인쇄용 색 체계 | 화면(RGB)보다 색이 탁해질 수 있음 |

예를 들어 5cm 스티커를 300dpi로 인쇄하려면 가로세로 약 590픽셀 이상이 필요합니다(5 ÷ 2.54 × 300). 여유 있게 더 크게 준비하세요.

## 해상도 높이기와 배경 제거

AI 도구에서 나온 그림은 인쇄하기에 작은 경우가 있습니다.

1. 도구의 업스케일(확대) 기능이나 별도 업스케일 도구로 2~4배 키운다
2. 배경 제거 도구로 투명 배경 PNG를 만든다
3. 확대해서 외곽선이 뭉개지지 않았는지 확인한다
4. 디자인 도구에서 실제 인쇄 크기로 배치해 본다

> 5cm 원형 스티커 8종을 A6 크기 스티커 용지 한 장에 배치하려고 해. 재단 여백 2mm, 스티커 사이 간격 3mm 기준으로 가능한 배치 방법과 각 스티커 위치(mm)를 계산해 줘.

## 제작 업체 가이드 따라가기

스티커·굿즈 제작 업체는 대부분 **작업 가이드 파일**(템플릿)을 제공합니다. 업체마다 칼선 그리는 방법, 파일 형식(PDF·AI·PNG), 색상 모드가 다르니 반드시 그 업체의 가이드를 내려받아 그 위에 작업하세요.

- [ ] 업체 템플릿 크기와 내 파일 크기가 같다
- [ ] 글자와 중요한 그림이 안전 영역 안에 있다
- [ ] 칼선이 업체가 정한 방식으로 그려져 있다
- [ ] 처음에는 **샘플(소량)을 먼저 주문**해 색과 칼선을 확인한다

### 오늘의 실천
- [ ] 제작 업체 2~3곳의 작업 가이드 내려받기
- [ ] 그림 해상도 계산하고 업스케일하기
- [ ] 샘플 주문용 파일 완성하기

# 5장. 제작과 원가: 소량으로 시작하는 계산법

## 제작 방식 비교

| 방식 | 내용 | 장점 | 단점 |
|---|---|---|---|
| 직접 소량 주문 | 업체에 수십~수백 장 주문 후 직접 포장·발송 | 품질 확인 가능, 단가 낮아짐 | 재고와 포장·발송 일이 생김 |
| 주문형 제작(POD) 플랫폼 | 주문이 들어오면 플랫폼이 제작·발송 | 재고 없음 | 내 마진이 작고, 품질 관리가 어렵다 |
| 디지털 상품 | 파일로 판매 | 제작비 없음 | 가격이 낮고 무단 공유 위험 |

국내외에 여러 주문형 제작 서비스가 있으며, 수수료와 정산 방식은 서비스마다 다르고 자주 바뀝니다(작성일 기준). 가입 전에 수수료와 저작권 관련 규정을 확인하세요.

## 원가와 가격 계산표

직접 소량 주문이라면 한 세트당 원가를 아래처럼 계산합니다.

| 항목 | 금액(세트당) |
|---|---|
| 제작비 (총액 ÷ 수량) | |
| 포장재 (OPP 봉투, 대지, 스티커) | |
| 배송비 중 내가 부담하는 부분 | |
| 판매 수수료 (판매가 × 수수료율) | |
| 결제 수수료 | |
| **합계 원가** | |

> 아래 비용으로 스티커 한 세트의 원가를 계산하고, 마진율 30%·40%·50%일 때 판매가를 각각 알려 줘. 판매 수수료는 판매가의 [수수료율]%로 계산해 줘.
> 제작비 총액: [금액] / 수량: [수량] / 포장재 1세트: [금액] / 배송비 부담: [금액]

계산 결과와 비슷한 상품의 실제 판매가를 비교해, 지나치게 비싸거나 싸지 않은지 확인하세요.

## 재고를 줄이는 시작법

1. 샘플을 주문해 직접 써 보고 사진을 찍는다
2. SNS에 디자인을 먼저 보여 주고 반응을 본다
3. 반응이 있는 디자인만 최소 수량으로 제작한다
4. 팔린 속도를 보고 다음 수량을 정한다

# 6장. 판매 채널과 상세페이지

| 핸드메이드·창작 마켓 | 창작 굿즈를 찾는 고객이 많다. 입점 심사가 있는 곳도 있다 |
| 오픈마켓·스마트스토어 | 검색 유입 중심. 키워드와 상세페이지가 중요하다 |
| 주문형 제작 플랫폼 | 재고 없이 시작. 플랫폼 안 노출에 의존한다 |
| SNS + 링크 판매 | 팬이 생기면 수수료 부담이 적다. 직접 홍보가 필요하다 |
| 오프라인 마켓·플리마켓 | 고객 반응을 직접 볼 수 있다 |

각 채널의 수수료, 입점 조건, 판매 가능 품목은 작성일 기준으로도 자주 바뀌니 가입 전 공식 안내를 확인하세요. 처음에는 **한두 곳**에 집중하는 것을 권합니다.

## 상품 사진 찍는 법

- 실제 인쇄된 샘플을 찍는다 (AI 그림만 올리지 않는다)

## 시리즈로 넓히는 방법
