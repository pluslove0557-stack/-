# AI로 엑셀 업무 자동화 입문
_수식을 외우지 않아도 되는 직장인의 반복 업무 줄이기 가이드_

# 프롤로그

매주 월요일 아침, 지난주 매출 파일을 열어 복사하고 붙여 넣고, 거래처 이름을 맞추고, 합계를 다시 계산하는 데 한두 시간을 쓰고 있지 않나요? 엑셀 업무의 상당수는 **같은 작업의 반복**입니다. 그런데 함수나 매크로를 따로 배우기에는 시간이 없고, 검색해서 찾은 수식은 내 파일에 맞지 않아 결국 손으로 하게 됩니다.

이 책은 AI를 **엑셀 옆자리 동료**처럼 써서 반복 업무를 줄이는 방법을 안내합니다. 수식을 처음부터 외우지 않아도, 내 표의 구조를 AI에게 정확히 설명하는 법만 익히면 필요한 수식과 정리 순서를 받아 낼 수 있습니다. 데이터 정리, 조회 함수, 요약표, 반복 작업 자동화, 그리고 결과 검증까지 순서대로 따라 합니다.

> 이 책의 약속: 책을 다 읽고 나면 매주 반복하는 엑셀 업무 하나를 골라, AI의 도움으로 수식·요약표·자동화 순서를 갖춘 '나만의 업무 템플릿'으로 바꿀 수 있습니다.

절약되는 시간은 업무 종류와 파일 상태에 따라 크게 다르며, 이 책은 특정 시간 단축을 약속하지 않습니다. 또한 엑셀의 함수와 AI 기능은 버전과 구독 요금제에 따라 쓸 수 있는 것이 다르고 자주 바뀝니다. 책에 적힌 내용은 **작성일(2026년 11월) 기준**이니, 내 엑셀 버전과 회사 보안 정책을 먼저 확인해 주세요.

# 1장. 어떤 업무를 자동화할까: 반복 업무 찾기

## 반복 업무 기록표

일주일 동안 엑셀로 한 일을 아래 표에 적어 보세요. 기억에 의존하지 말고 그때그때 적는 것이 중요합니다.

| 업무 | 빈도 | 걸린 시간 | 매번 같은 순서인가 | 실수가 잦은가 |
|---|---|---|---|---|
| 주간 매출 합치기 | 주 1회 | | 예 | 예 |
| 거래처 코드로 이름 찾기 | 매일 | | 예 | 아니오 |
| 월말 부서별 요약 | 월 1회 | | 예 | 예 |

## 자동화하기 좋은 업무의 조건

아래 네 가지 중 세 개 이상에 해당하면 첫 자동화 대상으로 좋습니다.

- 매번 **같은 순서**로 한다
- 입력 파일의 **모양(열 이름·순서)이 같다**
- 결과물의 **형식이 정해져 있다**
- 손으로 할 때 **실수가 자주 난다**

반대로 매번 판단이 달라지는 업무(예: 예외 거래 검토)는 자동화보다 체크리스트가 더 맞습니다.

## AI와 회사 데이터 다루는 원칙

엑셀 파일에는 고객 정보, 매출, 급여처럼 민감한 정보가 많습니다. AI를 쓰기 전에 아래를 지키세요.

1. 회사가 허용한 AI 도구인지, 보안 정책을 먼저 확인한다
2. AI에게는 **실제 데이터 대신 표의 구조**(열 이름, 예시 몇 줄)를 알려 준다
3. 예시 데이터는 이름·번호를 가짜 값으로 바꿔 넣는다
4. 원본 파일은 항상 복사본을 만들어 놓고 작업한다

이 책의 프롬프트는 모두 **실제 데이터 없이 구조만으로** 쓸 수 있게 만들었습니다.

# 2장. AI에게 내 표를 설명하는 법

## 표 설명 템플릿

"매출 합계 구하는 수식 알려 줘"라고만 물으면 내 파일에 맞지 않는 답이 나옵니다. 아래 템플릿으로 설명하세요.

> 나는 [엑셀 버전]을 쓰고 있어.
> 시트 이름은 [시트명]이고, 데이터는 [A1:F500] 범위에 있어. 1행은 제목 행이야.
> 열 구성: A열 날짜(2026-11-01 형식), B열 거래처코드(텍스트), C열 품목, D열 수량(숫자), E열 단가(숫자), F열 금액(숫자)
> 하고 싶은 것: [원하는 결과를 구체적으로]
> 결과를 넣을 위치: [시트명의 셀 위치]
> 수식과 함께, 수식이 어떻게 작동하는지 한 줄씩 설명해 줘.

열 이름, 자료형(텍스트·숫자·날짜), 범위, 결과 위치 네 가지만 정확해도 답의 정확도가 크게 달라집니다.

## 예시 데이터 만드는 법

실제 데이터 대신 **가짜 예시 3~5줄**을 함께 주면 AI가 표의 모양을 더 잘 이해합니다.

| 날짜 | 거래처코드 | 품목 | 수량 | 단가 | 금액 |
|---|---|---|---|---|---|
| 2026-11-01 | C001 | 볼펜 | 10 | 500 | 5000 |
| 2026-11-01 | C002 | 노트 | 5 | 2000 | 10000 |
| 2026-11-02 | C001 | 노트 | 3 | 2000 | 6000 |

실제 거래처명과 금액은 넣지 않습니다.

## 버전 알려 주기

엑셀은 버전에 따라 쓸 수 있는 함수가 다릅니다. 예를 들어 XLOOKUP, FILTER, UNIQUE 같은 함수는 비교적 최근 버전(Microsoft 365, Excel 2021 이후 등)에서 쓸 수 있고, 예전 버전에서는 오류가 납니다(작성일 기준). 버전은 엑셀의 [파일] → [계정] 화면에서 확인할 수 있습니다.

> 내 엑셀은 [버전]이야. 이 버전에서 쓸 수 없는 함수는 쓰지 말고, 꼭 필요하면 대체 방법을 함께 알려 줘.

구글 스프레드시트를 쓴다면 그렇다고 알려 주세요. 함수 이름과 동작이 일부 다릅니다.

# 3장. 데이터 정리: 자동화 전에 표부터 고르기

## 깨끗한 표의 다섯 규칙

자동화가 실패하는 가장 흔한 이유는 수식이 아니라 **표의 모양**입니다.

| 규칙 | 나쁜 예 | 좋은 예 |
|---|---|---|
| 한 행에 한 건 | 한 칸에 여러 품목 | 품목마다 한 행 |
| 병합 셀 없음 | 거래처명 셀 병합 | 모든 행에 거래처명 |
| 한 열에 한 종류 | 숫자와 "없음" 섞임 | 숫자만, 빈칸은 비워 둠 |
| 제목 행은 한 줄 | 2~3줄 제목 | 1행에 열 이름 |
| 중간 합계 없음 | 데이터 중간에 소계 | 소계는 따로 요약표에 |

## AI로 정리 순서 받기

> 아래는 내가 매주 받는 엑셀 파일의 상태야. 자동화하기 좋은 '한 행에 한 건' 형태로 바꾸고 싶어.
> 현재 상태: [병합 셀이 있다, 날짜가 텍스트로 들어 있다, 금액에 '원'이 붙어 있다 등]
> 원하는 형태: [열 이름 목록]
> 엑셀 기능(텍스트 나누기, 찾기 및 바꾸기, 중복 제거 등)과 수식을 이용한 정리 순서를 단계별로 알려 줘. 각 단계 전에 확인할 점도 적어 줘.

자주 쓰는 정리 작업 예시입니다.

- 앞뒤 공백 지우기: TRIM 함수
- 텍스트로 된 숫자를 숫자로: VALUE 함수 또는 [텍스트 나누기]
- '원', ',' 같은 문자 지우기: [찾기 및 바꾸기]
- 중복 행 지우기: [데이터] → [중복된 항목 제거]

정리 작업 전에는 반드시 **원본 복사본**을 만들어 두세요.

## 표 서식(테이블) 활용

데이터 범위를 선택하고 [삽입] → [표](단축키 Ctrl+T)로 바꾸면 다음 장점이 있습니다.

- 행을 추가하면 수식과 서식이 자동으로 따라온다
- 범위가 자동으로 늘어나 요약표가 새 데이터를 놓치지 않는다
- 열 이름으로 수식을 쓸 수 있어 읽기 쉽다

AI에게 질문할 때도 "데이터는 '매출표'라는 이름의 표야"라고 알려 주면 표 이름을 쓰는 수식을 받을 수 있습니다.

# 4장. 조회·집계 수식: 자주 쓰는 다섯 가지 패턴

## 다섯 가지 수식 패턴

| 하고 싶은 일 | 대표 함수 | 예 |
|---|---|---|
| 코드로 이름 찾기 | XLOOKUP (예전 버전: VLOOKUP, INDEX+MATCH) | 거래처코드 → 거래처명 |
| 조건에 맞는 합계 | SUMIFS | 11월, C001 거래처의 금액 합계 |
| 조건에 맞는 개수 | COUNTIFS | 이번 주 주문 건수 |
| 중복 없는 목록 | UNIQUE (예전 버전: 중복 제거 기능) | 거래처 목록 |
| 오류 대신 빈칸 | IFERROR | 못 찾으면 "확인 필요" 표시 |

이 다섯 가지를 조합하면 대부분의 주간·월간 보고 표를 만들 수 있습니다.

## AI에게 수식 받고 이해하기

> [2장의 표 설명 템플릿]
> 하고 싶은 것: '요약' 시트의 A열에 있는 거래처코드마다, '매출' 시트에서 11월 금액 합계를 B열에 구하고 싶어.
> 수식을 B2에 넣고 아래로 채울 수 있게 만들어 줘. 절대참조($)가 필요한 곳도 표시해 줘.
> 수식의 각 부분이 무엇을 뜻하는지 표로 설명해 줘.

수식을 받으면 **바로 붙여 넣지 말고** 설명을 읽고 아래를 확인하세요.

- 범위가 내 데이터 전체를 포함하는가
- 조건의 날짜 범위가 맞는가 (11월 1일~30일)
- 아래로 채웠을 때 참조가 어긋나지 않는가

## 수식 오류 해결 프롬프트

> 아래 수식을 넣었더니 [#N/A / #VALUE! / 0 / 예상과 다른 값]이 나와.
> 수식: [수식]
> 데이터 예시: [가짜 예시 3줄]
> 가능한 원인을 확률이 높은 순서대로 알려 주고, 각각 확인하는 방법도 알려 줘.

흔한 원인은 이렇습니다.

- 코드 앞뒤에 공백이 있다 → TRIM
- 한쪽은 숫자, 한쪽은 텍스트 형식이다 → 형식 통일
- 날짜가 텍스트로 들어 있다 → 날짜 형식으로 변환
- 범위를 고정하지 않아 아래로 채울 때 밀렸다 → $ 추가

# 5장. 요약표와 보고서: 피벗 테이블과 조건부 서식

## 원본·요약 분리 구조

자동화된 보고서는 보통 세 개의 시트로 나뉩니다.

| 시트 | 역할 | 매주 하는 일 |
|---|---|---|
| 원본 | 받은 데이터를 그대로 붙여 넣는 곳 | 새 데이터 붙여 넣기 |
| 기준 | 거래처 목록, 목표값 같은 고정 정보 | 거의 바꾸지 않음 |
| 요약 | 수식이나 피벗으로 자동 계산 | 새로 고침만 |

이렇게 나누면 매주 하는 일이 '붙여 넣고 새로 고침'으로 줄어듭니다.

## 피벗 테이블 만들기

수식 없이 집계하려면 피벗 테이블이 가장 빠릅니다.

1. 원본 표 안의 셀 하나를 선택한다
2. [삽입] → [피벗 테이블]을 누른다
3. 새 시트에 만들기를 선택한다
4. 행에는 '거래처', 열에는 '월', 값에는 '금액'을 끌어 놓는다
5. 원본이 바뀌면 [새로 고침]을 누른다

> 나는 [엑셀 버전]을 쓰고 있어. 원본 표의 열은 [열 목록]이야. '부서별·월별 금액 합계와 전월 대비 증감'을 보여 주는 피벗 테이블을 만들고 싶어. 행·열·값·필터에 무엇을 넣을지, 그리고 증감을 표시하는 설정 방법을 단계별로 알려 줘.

메뉴 위치와 이름은 버전에 따라 조금씩 다를 수 있습니다.

## 조건부 서식으로 눈에 띄게

보고서를 보는 사람이 한눈에 알 수 있도록 규칙을 정해 색을 입힙니다.

- 목표 대비 90% 미만이면 빨간색
- 전주 대비 증가하면 초록색
- 빈칸(데이터 누락)은 노란색

> 요약 시트의 C2:C30에 달성률(소수, 0.85는 85%)이 있어. 0.9 미만은 연한 빨강, 1 이상은 연한 초록으로 표시하는 조건부 서식 규칙을 만드는 방법을 단계별로 알려 줘.

색은 세 가지 이내로 쓰는 것이 읽기 좋습니다.

# 6장. 반복 작업 자동화: 매크로·스크립트는 작게 시작하기

## 자동화 방법 고르기

엑셀 반복 작업을 자동화하는 방법은 여러 가지입니다. 쓸 수 있는 기능은 버전과 회사 정책에 따라 다릅니다(작성일 기준).

| 방법 | 특징 | 맞는 경우 |
|---|---|---|
| 매크로 기록 | 내 동작을 녹화해 다시 실행 | 클릭 순서가 늘 같은 작업 |
| VBA 매크로 | 코드로 세밀하게 제어 (데스크톱 엑셀) | 여러 파일·시트를 반복 처리 |
| Office 스크립트 | 웹 엑셀 등에서 쓰는 스크립트 (요금제에 따라 다름) | 클라우드 중심 업무 |
| 파워 쿼리 | 여러 파일을 불러와 합치고 정리 | 매주 같은 모양의 파일 합치기 |

처음이라면 **파워 쿼리**나 **매크로 기록**부터 시작하는 것이 부담이 적습니다. 회사에 따라 매크로 실행이 막혀 있을 수 있으니 먼저 확인하세요.

## AI로 매크로 만들기 순서

한 번에 큰 매크로를 부탁하지 말고, 작업을 단계로 쪼개서 요청합니다.

> 나는 [엑셀 버전] 데스크톱에서 VBA 매크로를 처음 써 봐.
> 하고 싶은 일: '원본' 시트의 데이터를 지우고, 같은 폴더의 '이번주.xlsx' 파일 첫 시트 데이터를 복사해 붙여 넣은 뒤, '요약' 시트의 피벗 테이블을 새로 고침.
> 1) 먼저 이 작업을 작은 단계로 나눠 설명해 줘.
> 2) 그다음 1단계만 하는 코드를 써 주고, 코드 한 줄마다 주석으로 설명을 달아 줘.
> 3) 파일이 없을 때 멈추고 메시지를 보여 주는 처리도 넣어 줘.

1단계가 잘 되면 2단계를 요청하는 식으로 하나씩 붙여 나갑니다.

## 실행 전 안전 수칙

- [ ] 원본 파일의 복사본에서 먼저 실행한다
- [ ] 코드에 삭제(Delete, Clear) 명령이 있으면 어느 범위를 지우는지 확인한다
- [ ] 출처를 모르는 매크로가 든 파일은 열지 않는다
- [ ] 매크로가 든 파일은 매크로 사용 형식(.xlsm)으로 저장한다
- [ ] 코드를 이해하지 못한 부분은 AI에게 다시 설명을 요청한다

AI가 쓴 코드도 틀릴 수 있습니다. 결과를 반드시 손 계산 몇 건과 비교하세요.

# 7장. 검증과 업무 템플릿: 믿을 수 있는 자동화 만들기

## 검증 셀 만들기

자동화가 조용히 틀리는 것이 가장 위험합니다. 요약 시트 한쪽에 **검증 셀**을 만들어 두세요.

| 검증 항목 | 방법 |
|---|---|
| 합계 일치 | 원본 금액 합계와 요약표 합계가 같은지 (=원본합계-요약합계 가 0인지) |
| 건수 일치 | 원본 행 수와 피벗의 총 건수 비교 |
| 누락 확인 | 기준 시트에 없는 거래처코드 개수 (COUNTIFS로 확인) |
| 날짜 범위 | 원본의 가장 이른 날짜와 늦은 날짜 (MIN, MAX) |

> 요약 시트에 자동화가 제대로 됐는지 확인하는 검증 셀 4개를 만들고 싶어. 원본 표 구조는 [구조]이고, 요약표는 [위치]에 있어. 합계 일치, 건수 일치, 기준표에 없는 코드 개수, 날짜 범위를 확인하는 수식을 알려 주고, 문제가 있으면 "확인 필요"가 표시되게 해 줘.

검증 셀이 모두 정상일 때만 보고서를 보내는 습관을 들이세요.

## 업무 매뉴얼 한 장

자동화를 만든 사람만 쓸 수 있으면 휴가 때 업무가 멈춥니다. 한 장짜리 매뉴얼을 파일 첫 시트에 넣어 두세요.

1. 이 파일이 하는 일 (한 줄)
2. 매주 할 일 순서 (예: 원본 붙여 넣기 → 새로 고침 → 검증 확인)
3. 검증 셀이 '확인 필요'일 때 볼 곳
4. 수정하면 안 되는 시트와 셀
5. 마지막 수정 날짜와 수정한 사람
