# AI로 블로그 글 1시간에 3개 쓰기
_주제 찾기부터 발행까지, 초보를 위한 AI 블로그 루틴_

# 프롤로그

퇴근하고 노트북을 켭니다. 오늘은 꼭 글 하나 올리자고 마음먹었는데, 제목 하나 정하는 데 30분이 지나갑니다. 겨우 첫 문단을 쓰고 나면 사진 고르고, 글자 수 맞추고, 태그 붙이다가 자정이 넘습니다. 그렇게 사흘 쓰고 나면 블로그는 다시 조용해지죠.

블로그가 멈추는 이유는 대부분 실력이 아니라 **시간**입니다. 그리고 그 시간의 대부분은 '무엇을 쓸지 고민하는 시간'과 '빈 화면을 채우는 시간'에 들어갑니다. 바로 이 두 구간을 AI가 대신해 줄 수 있습니다.

이 책은 AI에게 글을 통째로 맡기는 방법이 아닙니다. 그렇게 만든 글은 읽는 사람도, 검색엔진도 금방 알아챕니다. 대신 **주제 찾기 → 구조 잡기 → 초안 → 내 경험 넣기 → 발행**까지 다섯 단계를 나누고, 각 단계에서 AI가 맡을 일과 내가 맡을 일을 정확히 갈라 드립니다.

> 이 책의 약속: 1시간 안에 내 목소리가 담긴 글 3개를 올리는 루틴을 손에 쥐게 됩니다.

책에 나오는 프롬프트는 모두 그대로 복사해서 쓸 수 있습니다. 챗GPT, 클로드, 제미나이 등 어떤 대화형 AI에서도 동작하도록 썼습니다. 각 서비스의 요금과 기능은 바뀔 수 있으니, 처음 쓰실 때 한 번 확인해 주세요.

# 1장. 왜 블로그는 일주일을 못 갈까

## 시간이 새는 세 구간

블로그 글 하나를 쓰는 과정을 쪼개 보면 시간이 새는 곳이 정확히 보입니다.

- **고민 구간**: 오늘 뭘 쓰지? 제목은 어떻게 하지? (평균적으로 가장 오래 걸리는 구간)
- **빈 화면 구간**: 첫 문장을 못 써서 커서만 깜빡이는 시간
- **마무리 구간**: 사진 정리, 소제목 다듬기, 태그·요약 작성

정작 '내 이야기를 쓰는 시간'은 전체의 일부에 불과합니다. 그런데 독자가 읽고 싶어 하는 건 바로 그 부분이죠.

## AI에게 맡길 일과 내가 할 일

이 책 전체를 관통하는 원칙은 하나입니다.

> AI는 뼈대와 초안을, 나는 경험과 판단을 맡는다.

| 단계 | AI가 할 일 | 내가 할 일 |
|---|---|---|
| 주제 찾기 | 후보 20개 뽑기 | 내가 쓸 수 있는 것 고르기 |
| 구조 잡기 | 소제목·순서 제안 | 독자에게 필요한 순서로 고치기 |
| 초안 | 문단 채우기 | 틀린 정보 지우기 |
| 내 경험 | 질문 던지기 | 답하기(사진·숫자·느낌) |
| 마무리 | 제목·태그·요약 후보 | 최종 선택 |

이렇게 나누면 내가 하는 일은 '고르고, 답하고, 고치는 것'뿐입니다. 빈 화면 앞에서 고민하는 시간이 사라집니다.

## 1시간 3개 루틴 미리보기

- 0~10분: 주제 3개 확정 (2장)
- 10~20분: 세 글의 구조를 한꺼번에 잡기 (3장)
- 20~35분: 초안 3개 받기 (4장)
- 35~50분: 내 경험 넣기 (5장)
- 50~60분: 제목·태그·발행 (6장)

처음에는 1시간 30분이 걸려도 괜찮습니다. 일주일만 반복하면 손이 기억합니다.

### 오늘의 실천
- [ ] 지난번 블로그 글 하나를 떠올리고, 세 구간 중 어디서 가장 오래 걸렸는지 적어 보기
- [ ] 쓰고 있는 AI 서비스 하나 정하기 (무료 버전으로 충분합니다)

# 2장. 10분 만에 쓸 주제 3개 정하기

## 주제 후보 20개 뽑는 프롬프트

아래 프롬프트에서 [ ] 부분만 바꿔 넣으세요.

> 나는 [블로그 주제: 예) 30대 직장인의 절약 생활]에 대해 블로그를 운영해. 내 독자는 [독자: 예) 사회초년생]이야. 이 독자가 네이버나 구글에 실제로 검색할 법한 질문형 주제 20개를 만들어 줘. 각 주제 옆에 '정보형/후기형/비교형' 중 무엇인지 표시해 줘.

질문형으로 받는 이유가 있습니다. 사람들은 검색창에 '절약'이 아니라 '월급 200 저축 얼마나'처럼 **질문**을 칩니다. 질문형 주제는 곧 검색어가 됩니다.

## 검색되는 주제 고르는 기준

20개 중에서 아래 세 가지를 통과하는 것만 남깁니다.

1. **내가 겪었거나 해 봤는가?** — 사진 한 장, 경험 한 줄이라도 넣을 수 있어야 합니다.
2. **검색창에 쳤을 때 자동완성이 뜨는가?** — 직접 네이버 검색창에 앞부분을 쳐 보세요. 자동완성에 비슷한 말이 뜨면 찾는 사람이 있다는 뜻입니다.
3. **한 글로 답할 수 있는가?** — '재테크 총정리'처럼 큰 주제는 여러 글로 쪼갭니다.

세 가지를 다 통과한 주제가 3개 나오면 오늘 쓸 글이 정해진 겁니다.

## 주제 은행 만들기

남은 후보는 버리지 마세요. 메모장이나 스프레드시트에 '주제 은행'을 만들어 쌓아 둡니다.

| 주제 | 유형 | 내 경험 | 쓴 날짜 |
|---|---|---|---|
| 월급 200 저축 얼마나 | 정보형 | 있음 | |
| 가계부 앱 3개 비교 | 비교형 | 있음 | |

주제 은행에 30개가 쌓이면 한 달 동안 '오늘 뭐 쓰지?'라는 고민이 사라집니다.

### 오늘의 실천
- [ ] 위 프롬프트로 주제 후보 20개 받기
- [ ] 세 가지 기준으로 오늘 쓸 주제 3개 고르기
- [ ] 나머지를 주제 은행에 옮겨 적기

# 3장. 세 글의 뼈대를 한 번에 잡기

## 소제목을 한 번에 받는 프롬프트

주제 3개를 정했다면 세 글의 뼈대를 한 번에 받습니다. 하나씩 따로 요청하는 것보다 훨씬 빠릅니다.

> 아래 블로그 글 3개의 구조를 각각 짜 줘. 글마다 [도입 1문단 요지 / 소제목 4~5개 / 마무리 요지] 형식으로. 독자는 [독자]이고, 글 길이는 각각 1,500~2,000자 정도야.
> 1) [주제1]
> 2) [주제2]
> 3) [주제3]

## 독자 순서로 고치기

AI가 준 순서는 '설명하기 편한 순서'인 경우가 많습니다. 독자가 궁금한 순서로 바꿔야 끝까지 읽힙니다. 기준은 간단합니다.

- 독자가 **가장 먼저 알고 싶은 것**(결론, 가격, 방법)을 앞으로
- 배경 설명, 역사, 정의는 뒤로 보내거나 지우기
- 소제목 하나에 질문 하나만 답하기

예를 들어 '가계부 앱 비교' 글이라면 '가계부의 역사'는 지우고, '결론부터: 이런 분은 이 앱'을 맨 위로 올립니다.

## 글 유형별 기본 뼈대

자주 쓰는 세 유형의 뼈대를 외워 두면 AI 답을 고치는 시간이 줄어듭니다.

**정보형**: 결론 요약 → 왜 중요한가 → 방법 단계별 → 주의할 점 → 정리

**후기형**: 왜 선택했나 → 써 보니 좋은 점 → 아쉬운 점 → 이런 분께 추천

**비교형**: 한 줄 결론 → 비교표 → 항목별 차이 → 상황별 추천

> 팁: 비교형 글에는 표가 하나만 있어도 체류 시간이 길어집니다. AI에게 '비교표를 마크다운 표로 만들어 줘'라고 따로 요청하세요.

### 오늘의 실천
- [ ] 주제 3개의 뼈대를 한 번에 받기
- [ ] 각 뼈대에서 '독자가 제일 궁금한 것'을 맨 위로 옮기기

# 4장. 15분 만에 초안 3개 받기

## 초안 요청 프롬프트

뼈대가 정해졌으면 초안은 한 편씩 요청합니다. 세 편을 한 번에 요청하면 글이 짧아지고 뭉뚱그려지기 쉽습니다.

> 아래 구조로 블로그 글 초안을 써 줘.
> - 독자: [독자]
> - 말투: 친구에게 알려 주듯 편한 존댓말, 문단은 3줄 이내
> - 길이: 1,500~2,000자
> - 구조: [3장에서 고친 뼈대 붙여넣기]
> - 내 경험이 들어갈 자리에는 [경험: ○○에 대해]라고 빈칸으로 남겨 줘.

마지막 줄이 핵심입니다. AI가 경험을 지어내지 않고 **빈칸**으로 남겨 두게 하면, 5장에서 그 자리만 채우면 됩니다.

## AI 말투 걷어내는 지시

초안을 받으면 아래 문장을 한 번 더 보내세요.

> 다음 표현을 고쳐 줘: '~에 대해 알아보겠습니다', '결론적으로', '다양한', '매우', 같은 어미가 세 번 이상 반복되는 부분. 추상적인 문장은 구체적인 예시로 바꿔 줘.

이 한 번으로 'AI가 쓴 티'가 상당 부분 줄어듭니다.

## 틀린 정보 걸러내기

AI는 그럴듯하게 틀린 말을 할 수 있습니다. 특히 아래 세 가지는 반드시 직접 확인합니다.

- **숫자**: 가격, 금리, 통계, 날짜
- **이름**: 앱·서비스 이름, 기관명, 제품 모델명
- **정책**: 세금, 지원금, 약관처럼 자주 바뀌는 것

확인할 수 없는 숫자는 과감히 지우세요. 틀린 숫자 하나가 글 전체의 신뢰를 무너뜨립니다.

### 오늘의 실천
- [ ] 초안 3개 받기 (경험 자리는 빈칸으로)
- [ ] AI 말투 걷어내기 지시 보내기
- [ ] 숫자·이름·정책에 형광펜 칠하고 직접 확인하기

# 5장. 내 경험을 넣어 '사람 글' 만들기

## AI가 나를 인터뷰하게 하기

빈칸을 채우는 가장 쉬운 방법은 AI에게 질문을 받는 것입니다.

> 이 글의 [경험] 빈칸을 채우려고 해. 나에게 짧은 질문을 5개 해 줘. 내가 답하면 그 답을 원래 문장에 자연스럽게 넣어 줘. 내 답에 없는 내용은 추가하지 마.

질문에 한두 줄씩 대충 답해도 됩니다. 말하듯 쓴 답이 오히려 더 생생합니다.

## 경험을 넣는 네 가지 재료

길게 쓸 필요는 없습니다. 아래 네 가지 중 하나만 있어도 글이 달라집니다.

1. **숫자**: "한 달 써 보니 커피값이 4만 원 줄었어요"
2. **장면**: "월급날 아침, 통장 알림을 보고 한숨부터 나왔어요"
3. **실수**: "처음엔 카테고리를 20개나 만들었다가 사흘 만에 포기했어요"
4. **느낌**: "솔직히 첫 주는 귀찮았는데, 2주 차부터는 재밌더라고요"

특히 **실수**는 독자의 신뢰를 가장 빨리 얻는 재료입니다. 완벽한 사람보다 한 발 앞서 넘어져 본 사람의 말을 더 믿기 때문입니다.

## 사진은 직접 찍기

AI 이미지나 인터넷에서 가져온 사진보다 휴대폰으로 직접 찍은 사진 한 장이 낫습니다.

- 글 하나에 사진 3~5장이면 충분합니다
- 화면 캡처도 훌륭한 사진입니다 (개인정보는 가리기)
- 다른 사람 사진·로고를 쓸 때는 사용 허락과 출처를 확인하세요

> 원칙: 내가 겪지 않은 일은 쓰지 않는다. 이 원칙 하나가 블로그를 오래 살아남게 합니다.

### 오늘의 실천
- [ ] 인터뷰 프롬프트로 빈칸 채우기
- [ ] 글마다 네 가지 재료 중 하나 이상 넣기
- [ ] 직접 찍은 사진 3장 준비하기

# 6장. 제목·태그·발행 10분 마무리

## 클릭되는 제목 후보 받기

제목은 직접 짓지 말고 후보를 받아서 고릅니다.

> 이 글의 블로그 제목 후보 10개를 만들어 줘. 조건: 검색어 [핵심 검색어]를 앞쪽에 넣기, 30자 안팎, 과장·낚시 표현 금지, 숫자나 구체적 결과가 들어간 것 5개 포함.

고를 때 기준은 두 가지입니다.

- 검색어가 **앞쪽**에 있는가
- 글 내용과 **정확히 일치**하는가 (제목만 화려하면 바로 나가 버립니다)

## 태그와 요약 한 번에

> 이 글에 어울리는 태그 10개와, 글 첫머리에 넣을 3줄 요약을 만들어 줘.

3줄 요약은 글 맨 위에 두세요. 바쁜 독자는 요약만 보고 계속 읽을지 결정합니다.

## 발행 전 1분 점검표

| 점검 항목 | 확인 |
|---|---|
| 숫자·이름·정책을 직접 확인했다 | |
| 내 경험이 한 줄 이상 들어갔다 | |
| 문단이 4줄을 넘지 않는다 | |
| 사진 출처·개인정보 문제가 없다 | |
| 제목과 내용이 일치한다 | |

다섯 칸이 모두 채워지면 바로 발행합니다. 완벽을 기다리면 영영 못 올립니다.

> 팁: 세 글을 한꺼번에 올리지 말고 예약 발행으로 하루에 하나씩 나눠 두면, 블로그가 매일 살아 있는 것처럼 보입니다.

### 오늘의 실천
- [ ] 제목 후보 10개 받고 하나 고르기
- [ ] 태그·3줄 요약 넣기
- [ ] 점검표 통과 후 발행 또는 예약 발행

# 7장. 루틴을 30일 이어가는 법

## 주 3회 1시간 일정표

매일 쓰려고 하면 지칩니다. 주 3회, 한 번에 1시간이면 한 주에 글 9개를 예약해 둘 수 있습니다.

| 요일 | 할 일 | 시간 |
|---|---|---|
| 월 | 주제 3개 + 뼈대 + 초안 | 35분 |
| 월 | 경험 넣기 + 발행 예약 | 25분 |
| 수 | 같은 루틴 반복 | 60분 |
| 토 | 같은 루틴 + 지난주 반응 보기 | 60분 |
