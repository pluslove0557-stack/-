나만의 스튜디오 - 바탕화면용 묶음
================================

[바탕화면에 두는 방법]
1. 받은 zip 파일을 바탕화면에 풀면 "GMC-Studio" 폴더가 생깁니다.
2. 폴더 안의 START.bat 을 더블클릭합니다.
   - 처음 한 번은 설치 때문에 몇 분 걸립니다(인터넷 필요).
   - Python 이 없다고 나오면 https://www.python.org/downloads/ 에서 설치하세요.
     설치 화면에서 "Add python.exe to PATH" 를 꼭 체크합니다.
3. 브라우저가 http://127.0.0.1:5000 으로 열립니다. 검은 창을 닫으면 프로그램이 꺼집니다.

[나만 쓰게 잠그기]
- 이 프로그램은 이 PC 에서만 열립니다(같은 와이파이의 다른 기기에서도 접속 불가).
- 비밀번호까지 걸려면 SET-PASSWORD.bat 을 실행해 비밀번호를 정하세요.
  이후에는 접속할 때 비밀번호를 묻습니다. 비밀번호는 암호화된 형태로만 저장됩니다.
- 비밀번호를 잊으면 program\data\.app_password 파일을 지우면 잠금이 풀립니다.

[들어 있는 것]
- START.bat .................. 자동소싱 프로그램 + 전자책 스튜디오 + 셀러 도구 5종
- 사주도령.html ............... 사주 앱 미리보기판 (더블클릭하면 브라우저에서 열림, 인터넷 불필요)
- 운세역전-타로(테스트판).html . 타로 앱 테스트판 (결제와 광고는 가짜로 동작)
- 토스등록준비 ................ 앱인토스 등록용 로고, 스크린샷, 콘솔 입력 문구, 체크리스트

[알아둘 점]
- 전자책 스튜디오는 Anthropic API 키가 없으면 "템플릿 모드"로 뼈대 원고만 만듭니다.
  실제 AI 원고를 쓰려면 Windows 환경변수 ANTHROPIC_API_KEY 를 설정한 뒤 START.bat 을 실행하세요.
- 내 데이터(소싱 후보, 전자책 원고)는 program\data 폴더에 저장됩니다. 이 폴더를 백업하세요.
- START.bat 은 Windows 용입니다. 맥에서는 터미널에서 program 폴더로 이동해
  python3 -m venv .venv && .venv/bin/pip install -r requirements.txt && .venv/bin/python run.py
