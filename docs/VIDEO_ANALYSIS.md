# 영상 분석 — "24시 풀오토 미국 쇼핑몰 / AI 신종 무역"

분석 대상
- 영상 1: 현장속으로 — "이건 100% 국내에서 저만 압니다…" (2026-11-10, 1시간 18분)
- 영상 2: 배움에 끝은없다 — "이런 마진은 처음 봅니다…" (2026-11-04, 26분)

두 영상 모두 같은 출연자(쇼디, 97년생)가 나오고, 같은 유료 강의 신청 링크(moneyupclass)로 연결되는 **강의 홍보 영상**입니다.
본질은 **미국 아마존/월마트 → 국내 오픈마켓 해외구매대행(위탁, 무재고)** 입니다.

## 1. 영상에서 설명한 실제 작업 순서

| 단계 | 영상 속 설명 | 이 프로그램에서 |
|---|---|---|
| 아이디어 | "테슬라 관련 제품 팔고 싶어" → AI가 모델3/모델Y로 키워드를 넓혀줌, 트림별 호환 차이까지 | ① 아이디어 → 키워드 확장 + 검색 링크 + GPT 프롬프트 |
| 소싱 | 자기 판매 데이터를 넣은 커스텀 GPT가 잘 팔릴 상품을 골라 엑셀로 줌 | 내 판매이력 학습(유사도 점수) + 판매이력이 들어간 GPT 프롬프트 |
| 수집 | 엑셀을 수집 프로그램에 올림 → AI 카테고리 매칭 → 아마존 로그인 후 수집, "수집 제외 17개" | ② 가져오기(CSV/엑셀/붙여넣기, ASIN 중복 제거) + ③ 판매 불가 자동 제외 |
| 선별 기준 | "대한민국 무료배송 / 수입 관세 면제(예치금)", 30일 반품, 4~7일 배송 | 배송/반품 조건 점수, 관부가세 계산 |
| 가공 | 상품명을 한국어로 깔끔하게, AI 태그, 상세페이지 생성(호환·구성품) | 한국어 상품명(50자) · 태그 10개 · 구매대행 고지 상세페이지 · GPT 다듬기 프롬프트 |
| 등록 | 6대 마켓(쿠팡·네이버·G마켓·옥션·11번가·롯데온) 동시 등록 | 채널별 수수료 반영 판매가 + 등록용 엑셀 |
| 주문 | 주문 들어오면 아마존에서 구매, 한글 주소를 영문으로 | 주문 처리 도우미(영문 주소, 통관부호 형식 검사) |
| 마진 올리기 | 같은 상품을 1688/타오바오 이미지 검색 → 중국에서 사서 보냄 → 70~80% | 중국 조달 비교 계산 + **위조/허위표시 경고** |
| 운영 전략 | 광고 0원. "30일에 1개 팔리는 상품 30개 = 매일 1건", 상품 수로 승부 | 롱테일 플래너 |
| 상품 성격 | 미국차(테슬라·GMC·포드) 부품, 국내에 없는 미국 브랜드 소모품, 브랜드 상품은 상세페이지 없이도 팔림 | '미국전용 수요' 가점, 브랜드 가점 |

## 2. 영상에서 걸러 들어야 할 부분

- **"국내에서 저만 압니다"** — 아마존 글로벌 배송을 이용한 미국 구매대행은 오래전부터 있던 방식입니다. 새로운 건 AI로 상품명/태그 가공 속도가 빨라졌다는 점 정도입니다.
- **하루 6만 개 수집·등록** — 마켓별 등록 상품 수 제한과 품질 정책이 있습니다. 대량 등록은 계정 제재 위험이 있습니다.
- **매출 인증(월 1억, 순익 3천 등)** — 출연자 주장이고 강의 판매가 목적인 영상입니다. 같은 영상에서도 육아 아빠 사례는 월매출 2,900만 원, 초기 3개월은 매출 0이었다고 말합니다.
- **중국에서 같은 제품을 사서 보내기** — 무브랜드 범용품을 *중국산으로 정직하게 따로 등록*하면 문제없습니다. 하지만 **미국 브랜드 상품으로 올려놓고 중국 유사품을 보내면 상표권 침해·허위표시**가 될 수 있습니다. 이 프로그램은 브랜드 상품에 경고를 띄웁니다.
- **아마존 자동 로그인·자동 수집** — 아마존 이용약관상 자동 크롤링은 금지되어 있어 계정이 막힐 수 있습니다. 이 프로그램은 링크/CSV 방식으로 만들었습니다.
- **"지재권 걱정 없음", "CS 거의 없음"** — 금지어 필터가 줄여 주긴 하지만 없애 주지는 않습니다. 전기용품·어린이제품은 구매대행이라도 KC 관련 요건이 있습니다.
- **필수 준비**: 사업자등록, 통신판매업 신고, 해외구매대행 표기, 개인통관고유부호 수집, 반품 배송비 고지.

## 3. 그대로 가져다 쓸 만한 핵심 아이디어

1. 국내에서 구하기 어려운 **미국 전용 수요**(미국차 부품·액세서리, 미국 브랜드 소모품)를 노린다.
2. **'한국 무료배송 + 관부가세 예치금'이 뜨는 상품만** 고르면 원가 계산이 쉽고 배송이 빠르다.
3. 한 상품을 많이 파는 대신 **천천히 팔리는 상품을 많이** 올려 광고 없이 주문을 쌓는다.
4. **내가 실제로 판 상품과 비슷한 것**을 우선 찾는다(판매이력 기반 소싱).
5. 원가는 반드시 **국내 최저가와 비교**해서 마진을 본다.

# 영상 3 — 인스타 릴스 "grounded. 필라테스 양말" (thevibefounder, 43초)

https://www.instagram.com/reel/DgAPjQdPWXT/

**주장**: 투자 0원으로 30일 만에 $3M 브랜드. 핵심 문장은 "아이디어에서 시작하지 말고 수요에서 시작하라"입니다.

| 단계 | 릴스 내용 | 프로그램 반영 (`/trend`) |
|---|---|---|
| 1. 수요 | 구글 트렌드로 'Pilates' 5년 검색량 상승 확인 | 구글 트렌드/네이버 데이터랩 CSV → 상승·유지·하락, 전년 대비, 계절성, 추이 그래프 |
| 2. 상품 발굴 | 작은 필라테스 유튜버들의 "day in the life" 자막을 ChatGPT에 넣어 반복 등장 제품 추출 → 그립 양말 | 자막 여러 개 → **몇 명이 공통으로 말했는지** 기준 반복 단어 순위 (외부 API 없음) + GPT 프롬프트 |
| 3. 소싱 | 알리바바에서 개당 $0.75~1.05에 소싱, 'grounded.' 브랜드로 $18.99 판매 | 사입 원가 계산기: 공장 단가·MOQ·운송·관세·포장 → 개당 순이익, 광고비 한도, 첫 재고 자금, 회수 판매 수 |
| 4. 마케팅 | 숏폼: 미끄러지는 **문제** → 양말로 **해결** | 브랜드명 후보(+KIPRIS 상표·도메인·인스타 확인 링크), '문제→해결' 15초 대본 3개 |

**걸러 들을 부분**
- "$3M / 30일 / 투자 0원"은 확인되지 않은 수치입니다. 알리바바 사입은 MOQ만큼 **재고 자금이 먼저 들어갑니다**. 구매대행(무재고)과 달리 돈이 묶입니다.
- 원가 $1 대 판매가 $18.99는 운송비, 관세, 반품, 택배, 광고비를 뺀 숫자입니다. 계산기로 직접 확인하면 국내 기준 마진은 대략 30~40%대입니다.
- 브랜드명은 반드시 상표 검색(KIPRIS, 같은 상품류)을 거치세요. 공장 사진을 그대로 쓰지 말고 직접 찍은 영상을 쓰세요.

**미국 구매대행 흐름과의 관계**: 구매대행(`/us`)으로 잘 팔리는 물건을 먼저 확인하고, 반복해서 팔리는 무브랜드 품목만 `/trend`에서 자체 브랜드로 키우는 순서가 안전합니다.
