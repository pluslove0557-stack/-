# 셀러 자동화 툴킷 (Seller Automation Toolkit)

무재고/위탁판매 셀러가 반복적으로 하는 5가지 작업을 자동화하는 로컬 웹앱입니다.
쇼핑몰 강의 광고에서 "제공"한다고 홍보하던 부가자료(엑셀 마진 계산기, 이미지 변환 AI,
자동 상품등록, AI소싱기, 이미지 변환 프롬프터)를 실제로 동작하는 오픈소스 도구로
직접 구현했습니다.

## 포함된 5가지 도구

| # | 도구 | 설명 |
|---|------|------|
| 1 | 엑셀 마진 계산기 | 원가/판매가/수수료/광고비 등을 입력하면 개당마진, 마진율, 손익분기 판매가를 자동 계산. 엑셀로 내보내면 수식이 그대로 들어가서 값을 바꾸면 자동 재계산됨 |
| 2 | 이미지 변환 프로그램 | 상품 이미지 일괄 리사이즈/정사각형 패딩, 배경 제거(가능하면 AI, 아니면 단색 배경 감지 대체), 워터마크, 포맷 변환 |
| 3 | 자동 상품등록 도우미 | 내 상품 데이터(csv/xlsx)를 쿠팡/네이버/11번가 대량등록 양식 컬럼에 맞춰 자동 매핑 → 업로드용 파일 생성 |
| 4 | 소싱 스코어링(AI소싱기) | 도매 후보 상품 리스트를 마진율·수요(검색량)·경쟁강도로 자동 채점/랭킹 |
| 5 | 이미지 변환 프롬프터 | 배경/조명/앵글/톤을 고르면 AI 이미지 생성 도구(미드저니/달리/포토룸 등)에 바로 쓸 한글+영문 프롬프트 생성 |

## 왜 강의를 안 사고 직접 만들었나

광고에 나온 부가자료들은 실제로는 엑셀 서식, 범용 이미지 편집 프로그램, 상품 데이터
정리용 매크로/스프레드시트 수준의 도구들입니다. 동일한 기능을 파이썬으로 직접
구현하면 무료이고, 코드를 그대로 볼 수 있어 어떤 로직으로 계산/처리되는지
투명하게 확인할 수 있습니다.

**중요한 정직성 원칙:**
- "AI소싱기"는 실제 AI 모델이 아니라 마진율/수요/경쟁강도를 조합한 투명한 규칙
  기반 점수 계산기입니다. 스코어링 기준을 화면에 그대로 보여줍니다.
- "자동 상품등록"은 쿠팡/네이버/11번가에 크롤링이나 우회 방식으로 자동 게시하지
  않습니다. 각 플랫폼 정책상 정식 등록은 판매자센터 또는 공식 오픈API로만
  해야 하므로, 이 도구는 **내 데이터를 업로드 양식에 맞게 정리**하는 역할만 합니다.
- 이미지 배경 제거는 `rembg`(오픈소스 AI 세그멘테이션 모델)가 설치되어 있으면
  실제 AI 방식을, 없으면 흰색/단색 배경 감지 방식을 사용하며 UI에 어떤 방식이
  적용됐는지 표시합니다.

## 설치 및 실행

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

브라우저에서 http://localhost:5000 접속.

### (선택) 진짜 AI 배경제거 쓰기

```bash
pip install rembg onnxruntime
```

설치 후 서버를 재시작하면 이미지 변환 페이지 상단 배지가 "AI 배경제거 사용 가능"으로
바뀌고, 처리 시 실제 AI 세그멘테이션 모델이 사용됩니다. (첫 실행 시 모델 파일을
자동으로 내려받습니다.)

## 프로젝트 구조

```
app/

  margin.py           마진 계산 로직 + 엑셀(xlsx) 내보내기
  image_tool.py        이미지 처리 파이프라인 (리사이즈/배경제거/워터마크)
  listing.py          상품 데이터 → 채널별 등록 양식 매핑
  sourcing.py          소싱 후보 스코어링/랭킹
  prompts.py           이미지 변환 프롬프트 템플릿 생성
  routes/              각 도구별 Flask 라우트
  templates/            Jinja2 HTML 템플릿
  static/style.css      공통 스타일

```

## 각 도구 사용법 요약

### 1. 엑셀 마진 계산기 (`/margin`)
행을 추가해 상품별 원가/판매가/배송비/수수료율/광고비/기타비용/수량을 입력하면
개당마진·마진율·손익분기 판매가가 실시간으로 계산됩니다. "엑셀로 내보내기"를
누르면 `=C2-B2-D2-...` 같은 실제 엑셀 수식이 포함된 `.xlsx` 파일이 다운로드됩니다.

### 2. 이미지 변환 프로그램 (`/image`)
이미지를 여러 장 선택하고 옵션(배경 제거/정사각형 규격화/워터마크/포맷)을 고른 뒤
"변환 실행"을 누르면, 1장이면 단일 파일로, 여러 장이면 zip으로 다운로드됩니다.

### 3. 자동 상품등록 도우미 (`/listing`)
채널(쿠팡/네이버/11번가/공통) 템플릿을 고르고 내 상품 데이터 파일을 올리면,
컬럼을 자동으로 추천 매칭해줍니다. 확인/수정 후 "등록용 엑셀 생성"을 누르면
해당 채널 컬럼 순서에 맞춘 파일이 만들어집니다. **실제 최신 공식 양식과 반드시
비교 확인하세요.**

### 4. 소싱 스코어링 (`/sourcing`)
`상품명, 도매가, 예상판매가` (선택: `카테고리, 월간검색량, 경쟁상품수`) 컬럼을 가진
CSV를 올리면 마진율(60%) + 수요(25%) + 경쟁강도(15%) 가중치로 점수를 매겨
높은 순으로 정렬합니다. 검색량/경쟁상품수가 없으면 마진율 비중을 자동으로 높입니다.
샘플 CSV는 페이지에서 바로 받을 수 있습니다.

### 5. 이미지 변환 프롬프터 (`/prompts`)
제품명과 배경/조명/앵글/톤을 고르면 한글 설명 + 영문 프롬프트를 여러 개
생성합니다. 영문 프롬프트는 버튼 클릭으로 바로 복사해서 미드저니, 달리, 포토룸 AI,
캔바 등에 붙여넣을 수 있습니다.

## 라이선스 / 주의사항

개인/소상공인의 로컬 업무 자동화 목적의 도구입니다. 오픈마켓 대량등록 양식은
수시로 바뀌므로 실제 등록 전 각 플랫폼 판매자센터 공지를 반드시 확인하세요.
