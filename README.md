# 나만의 소싱 프로그램 (미국 구매대행 + 셀러 자동화 툴킷)

혼자 쓰는 로컬 웹앱입니다. 휴대폰 홈 화면에 앱처럼 설치할 수 있습니다(PWA).
유튜브 "24시 풀오토 미국 쇼핑몰 / AI 신종 무역" 영상 두 편을 분석해서 만든
**미국 소싱 파이프라인**(`/us`)이 메인이고, 기존 셀러 도구 5종은 `/tools`에 있습니다.
영상 분석 내용은 [docs/VIDEO_ANALYSIS.md](docs/VIDEO_ANALYSIS.md)에 정리했습니다.

## 미국 소싱 파이프라인 (`/us`)

| 단계 | 화면 | 하는 일 |
|---|---|---|
| ① | 아이디어 | "테슬라", "고양이" → 확장 키워드, 아마존/월마트/네이버/쿠팡 검색 링크, 내 판매이력이 들어간 GPT 소싱 프롬프트 |
| ② | 가져오기 | GPT가 준 CSV 붙여넣기, CSV/XLSX 업로드, 한 개씩 입력. ASIN 기준 중복 제거 |
| ③ | 후보 평가 | 판매 불가(의약품·도검·성인·명품·씨앗 등) 자동 제외, KC/식품/화장품 주의 표시, 원가·채널별 판매가·국내최저가 기준 마진·점수 |
| ④ | 상품 상세 | 원가 내역(환율·버퍼·배송·관부가세), 6대 마켓 권장가, 중국 조달 비교(브랜드 경고), 한국어 상품명/태그, 구매대행 고지 상세페이지 HTML |
| ⑤ | 내보내기 | '선정' 상품을 채널별 판매가 + 상품명 + 태그 + 상세 HTML 엑셀로 |
| ⑥ | 주문 처리 | 한글 주소/이름 → 아마존 배송지 영문, 개인통관고유부호 형식 검사 |
| + | 판매이력 학습 | 팔린 상품명을 넣으면 비슷한 후보 점수가 올라감 (단어 가중치 방식, 결과 공개) |
| + | 롱테일 플래너 | "30일에 1개 팔리는 상품 30개 = 하루 1건" — 목표 주문 수에 필요한 등록 수 |
| + | 설정 | 환율, 면세 한도, 관세율, 채널 수수료, 목표 마진 |

점수 = 마진 30% · 수요(리뷰/BSR) 20% · 국내경쟁 15% · 배송/반품 조건 15% · 브랜드/미국전용 10% · 판매이력 유사도 10%.

**하지 않는 것**: 아마존 자동 로그인/크롤링(이용약관 위반 위험), 마켓 자동 게시(공식 판매자센터/API 사용),
중국 유사품을 브랜드 상품으로 파는 것(상표권·허위표시 위험 — 화면에서 경고).

### 나만 쓰게 잠그기 / 휴대폰 앱으로 쓰기

```bash
APP_PASSWORD=원하는비밀번호 python run.py
```

기본은 이 PC에서만(127.0.0.1) 열리고 브라우저가 자동으로 뜬다. 비밀번호 잠금은 `python run.py --set-password`.
Windows 바탕화면용 실행 파일은 `desktop/START.bat` 참고(`desktop/사용법.txt`).

`APP_PASSWORD`를 정하면 모든 화면에 로그인이 필요합니다(30일 유지). 같은 와이파이의 휴대폰에서
`http://PC의IP:5000` 으로 들어가 브라우저 메뉴의 "홈 화면에 추가"를 누르면 앱처럼 설치됩니다.
밖에서도 쓰려면 PC를 켜 두고 Tailscale 같은 VPN으로 접속하는 걸 권장합니다(인터넷에 포트를 직접 열지 마세요).
데이터는 `data/sourcing.db`(SQLite) 한 파일에 저장됩니다 — 이 파일만 백업하면 됩니다.

## 기존 셀러 자동화 툴킷 (`/tools`)

무재고/위탁판매 셀러가 반복적으로 하는 5가지 작업을 자동화하고, 내 경험으로 전자책을 만들어 파는
10단계 **전자책 스튜디오**까지 담은 로컬 웹앱입니다.
쇼핑몰 강의 광고에서 "제공"한다고 홍보하던 부가자료(엑셀 마진 계산기, 이미지 변환 AI,
자동 상품등록, AI소싱기, 이미지 변환 프롬프터)를 실제로 동작하는 오픈소스 도구로
직접 구현했습니다.

## 포함된 5가지 도구

| # | 도구 | 설명 |
|---|------|------|
| 1 | 엑셀 마진 계산기 | 원가/판매가/수수료/광고비 등을 입력하면 개당마진, 마진율, 손익분기 판매가를 자동 계산. 엑셀로 내보내면 수식이 그대로 들어가서 값을 바꾸면 자동 재계산됨 |
| 2 | 이미지 변환 프로그램 | 상품 이미지 일괄 리사이즈/정사각형 패딩, 배경 제거(가능하면 AI, 아니면 단색 배경 감지 대체), 워터마크, 포맷 변환 |
| 3 | 자동 상품등록 도우미 | 내 상품 데이터(csv/xlsx)를 쿠팡/네이버/11번가 대량등록 양식 컬럼에 맞춰 자동 매핑 → 업로드용 파일 생성 |
| 4 | 소싱 스코어링(AI소싱기) | 도매 후보 상품 리스트를 마진율·수요(검색량)·경쟁강도로 자동 채점/랭킹 |
| 5 | 이미지 변환 프롬프터 | 배경/조명/앵글/톤을 고르면 AI 이미지 생성 도구(미드저니/달리/포토룸 등)에 바로 쓸 한글+영문 프롬프트 생성 |
| 6 | 나만의 전자책 스튜디오 | 주제 추천 → 시장성 검증 → 리서치 → 목차 → 원고 → 휴먼터치 → 표지 4종·3D 목업 → 모바일용 PDF → 판매 랜딩페이지 → 메타 광고 소재·성과 기록 → 수익화·콘텐츠(상품 계단, 카드뉴스, 30일 플랜, 해외 벤치마킹)까지 11단계 |

## 나만의 전자책 스튜디오 (`/ebook`)

"AI로 전자책 한 권을 만들어 파는" 과정을 한 화면에서 순서대로 진행합니다.

| 단계 | 하는 일 | 결과물 |
|---|---|---|
| 1. 주제 | 관심 분야(10개 카테고리·세부 분야), 독자 수준, 내 상황을 고르면 팔릴 주제 10개(부제·팔릴 근거·차별화 포함), "10개 더" | 주제 후보 |
| 2. 시장성 | (AI) 웹 검색으로 유튜브 조회수·유사 상품 리뷰·경쟁 상품의 빈틈 정리 / 유튜브·크몽·네이버·교보 검색 링크 | 판정 리포트 |
| 3. 리서치 | 리서치 수준(낮음/보통/높음)에 따라 국내 자료·해외 논문·통계를 출처와 함께 수집 | 리서치 노트 |
| 4. 목차 | 분량(슈퍼라이트 15쪽 ~ 딥 100쪽)과 말투(실용 매뉴얼/존댓말 다정/반말 직설/스토리텔링) 선택, 장마다 결론 한 문장 | 확정 목차 |
| 5. 원고 | 내 경험담·말투 샘플 반영, "테스트: 프롤로그 + 1장" 또는 전체 쓰기 | 프롤로그 + 장별 원고 |
| 6. 휴먼터치 | AI 상투구 제거, 사람 냄새 나는 문장으로 다듬기 | 다듬은 원고 |
| 7. 표지 | 설치된 한글 글꼴 선택, 임팩트/포스터/미니멀/클래식 4종 × 색 테마 5종, 3D 목업 | cover.png, mockup_3d.png |
| 8. 본문 PDF | 글꼴 내장, 모바일 가독성 줄간격의 A5 PDF (표·체크리스트 지원) | ebook.pdf |
| 9. 판매페이지 | 단일 HTML 판매 페이지, "HTML 코드 복사" 후 페이지 빌더에 붙여넣기 | landing.html |
| 10. 광고 | 광고 3개/6개(공감·결과·호기심·문제해결·추천·혜택형) 이미지와 문구, 광고비·클릭·판매·매출 기록 → 클릭당 비용·전환율·ROAS 계산 | ads/ 폴더 |
| 11. 수익화·콘텐츠 | 무료 미끼 → 저가 → 중가 → 고가 계단형 상품 구조, 노트 손글씨 느낌 카드뉴스 5장 + 캡션, 채널별 30일 콘텐츠 플랜, 해외 인기 콘텐츠 스크립트 분석 → 내 콘텐츠로 재구성 | cardnews/, marketing/ 폴더 |

8단계의 **최종 결과물 zip**에는 PDF, 수정용 원고(manuscript.md), 표지, 목업, 판매페이지, 광고 이미지·문구가 모두 들어 있습니다.

### AI 모드 켜기

```bash
export ANTHROPIC_API_KEY=sk-ant-...   # Windows: set ANTHROPIC_API_KEY=...
python run.py
```

- 키가 있으면 Claude(`claude-opus-5-5`, `EBOOK_MODEL`로 변경 가능)가 주제·검증·리서치·목차·원고·다듬기·판매문구를 작성합니다. 시장성 검증과 리서치는 웹 검색을 사용하고 출처를 붙이며, 확인되지 않은 수치는 지어내지 않도록 지시합니다.
- 키가 없으면 **템플릿 모드**로 동작합니다. 실제 AI가 아니라 직접 채워 쓰는 구조화된 초안과 체크리스트를 만들며, 화면 상단에 어떤 모드인지 표시합니다. 표지·PDF·판매페이지·광고 이미지는 두 모드 모두 동일하게 만들어집니다.
- 한글 글꼴은 설치된 것을 자동으로 찾아 목록에 보여줍니다(나눔고딕·나눔명조·맑은 고딕·Apple SD 고딕 Neo·Noto CJK 등). `data/fonts/` 폴더에 .ttf 파일을 넣거나 `EBOOK_FONT=/경로/폰트.ttf`(굵게: `EBOOK_FONT_BOLD`)를 지정해도 됩니다.
- 프로젝트는 `data/ebooks/<id>/`에 저장됩니다(git 추적 안 함).

### 정직성 원칙
- 수익을 보장하지 않습니다. 판매량은 주제·마케팅·가격에 달려 있습니다.
- 메타 광고는 자동 집행하지 않습니다. 소재를 만들어 주면 광고관리자에서 직접 올리고, 성과 숫자는 직접 옮겨 적어 계산합니다.
- 해외 콘텐츠 벤치마킹은 구조만 빌려 다시 쓰도록 안내합니다. 원문 번역·복제 게시는 저작권 침해가 될 수 있습니다.
- 판매 결제는 크몽·스마트스토어·토스페이 등 내 결제 링크를 판매페이지 버튼에 연결하는 방식입니다.
- AI가 쓴 원고도 사실관계와 출처를 반드시 직접 확인하고, 내 경험을 더해 출간하세요.

## 왜 강의를 안 사고 직접 만들었나

광고에 나온 부가자료들은 실제로는 엑셀 서식, 범용 이미지 편집 프로그램, 상품 데이터
정리용 매크로/스프레드시트 수준의 도구들입니다. 동일한 기능을 파이썬으로 직접
구현하면 무료이고, 코드를 그대로 볼 수 있어 어떤 로직으로 계산/처리되는지
투명하게 확인할 수 있습니다.

**중요한 정직성 원칙:**
- "AI소싱기"는 실제 AI 모델이 아니라 마진율/수요/경쟁강도를 조합한 투명한 규칙
  기반 점수 계산기입니다. 스코어링 기준을 화면에 그대로 보여줍니다.
- "자동 상품등록"은 쿠팡/네이버/11번가에 크롤링이나 우회 방식으로 자동 게시하지
  않습니다. 각 플랫폼 정책상 정식 등록은 판매자센터 또는 공식 오픈API로만
  해야 하므로, 이 도구는 **내 데이터를 업로드 양식에 맞게 정리**하는 역할만 합니다.
- 이미지 배경 제거는 `rembg`(오픈소스 AI 세그멘테이션 모델)가 설치되어 있으면
  실제 AI 방식을, 없으면 흰색/단색 배경 감지 방식을 사용하며 UI에 어떤 방식이
  적용됐는지 표시합니다.

## 각 도구 사용법 요약

### 1. 엑셀 마진 계산기 (`/margin`)
행을 추가해 상품별 원가/판매가/배송비/수수료율/광고비/기타비용/수량을 입력하면
개당마진·마진율·손익분기 판매가가 실시간으로 계산됩니다. "엑셀로 내보내기"를
누르면 `=C2-B2-D2-...` 같은 실제 엑셀 수식이 포함된 `.xlsx` 파일이 다운로드됩니다.

### 2. 이미지 변환 프로그램 (`/image`)
이미지를 여러 장 선택하고 옵션(배경 제거/정사각형 규격화/워터마크/포맷)을 고른 뒤
"변환 실행"을 누르면, 1장이면 단일 파일로, 여러 장이면 zip으로 다운로드됩니다.

### 3. 자동 상품등록 도우미 (`/listing`)
채널(쿠팡/네이버/11번가/공통) 템플릿을 고르고 내 상품 데이터 파일을 올리면,
컬럼을 자동으로 추천 매칭해줍니다. 확인/수정 후 "등록용 엑셀 생성"을 누르면
해당 채널 컬럼 순서에 맞춘 파일이 만들어집니다. **실제 최신 공식 양식과 반드시
비교 확인하세요.**

### 4. 소싱 스코어링 (`/sourcing`)
`상품명, 도매가, 예상판매가` (선택: `카테고리, 월간검색량, 경쟁상품수`) 컬럼을 가진
CSV를 올리면 마진율(60%) + 수요(25%) + 경쟁강도(15%) 가중치로 점수를 매겨
높은 순으로 정렬합니다. 검색량/경쟁상품수가 없으면 마진율 비중을 자동으로 높입니다.
샘플 CSV는 페이지에서 바로 받을 수 있습니다.

### 5. 이미지 변환 프롬프터 (`/prompts`)
제품명과 배경/조명/앵글/톤을 고르면 한글 설명 + 영문 프롬프트를 여러 개
생성합니다. 영문 프롬프트는 버튼 클릭으로 바로 복사해서 미드저니, 달리, 포토룸 AI,
캔바 등에 붙여넣을 수 있습니다.

## 라이선스 / 주의사항

개인/소상공인의 로컬 업무 자동화 목적의 도구입니다. 오픈마켓 대량등록 양식은
수시로 바뀌므로 실제 등록 전 각 플랫폼 판매자센터 공지를 반드시 확인하세요.
